# Глосарій

Доменні терміни Meridian і де вони живуть у коді. Правила — в `AGENTS.md` і
README тек.

| Термін | Що це | У коді |
|--------|-------|--------|
| План дієтолога | Джерело страв: PDF від дієтолога. У репозиторій не потрапляє | `meal.source` — підпис плану («План A»), не провенанс |
| Страва | Картка з плану: назва, тип, калорійність, БЖВ, інгредієнти, порції | `Meal` у `packages/core/src/types.ts`, таблиця `meal` |
| Рецепт | Кроки, час, порційність і фото страви; окремий рядок 1:1 | `Recipe`, таблиця `recipe` |
| Пул страв | Усі живі страви сім'ї; спільний для профілів | `useMeals`, `poolForProfile` |
| Слот | Прийом їжі: сніданок, обід, вечеря, перекус | `MealType`: `breakfast` / `lunch` / `dinner` / `snack` |
| Профіль | Раціон однієї людини: ціль, коридор, порція, підмножина пулу. Не акаунт | `Profile`, таблиця `profile` |
| Акаунт | Вхід у GoTrue. З профілем не пов'язаний | `auth.users`, `family_member` |
| Сім'я | Одиниця спільного доступу й синхронізації; один акаунт — одна сім'я | claim `family_id`, `current_family_id()` |
| Активний профіль | Профіль, відкритий на цьому пристрої; стан пристрою | `lib/active-profile.ts` |
| Власник спільного плану | Профіль, чий тиждень читають пов'язані профілі | `sharedPlanWith`, `planOwnerId` |
| Ціль калорійності | Калорійність дня, яку тримає генератор, ккал | `targetCalories` |
| Коридор | Допустиме відхилення дня від цілі, ±ккал; послаблюється до ±500 | `corridor`, `CORRIDOR_MAX` |
| Антиповтор | Страва не повторюється частіше, ніж раз на N днів, і через межу тижнів | `generator.ts`, `calendar.ts` |
| Мікс планів | Тиждень поєднує страви з різних планів дієтолога | `plans.ts` |
| Тиждень (план) | Результат генератора: дні від сьогодні, по страві на слот | `week_plan`, `plan_slot` |
| Календар | Ті самі слоти за датами; минулі дні не редагуються | `plan_slot`, `calendar.ts` |
| Ручна заміна | Заміна страви в одному слоті без перегенерації | `replace.ts`, `plan_slot.swapped` |
| Порційна літера | «Ж» / «Ч» — порція Жінка/Чоловік з плану, не жири | `Profile.portion`, `PortionLetter` |
| Готова порція | Рядок після «Готова порція:» дослівно | `meal.portions` |
| «≈» | Калорійність — оцінка з таблиць, а не цифра дієтолога | `caloriesApprox` |
| ГЕРХ | Страва з плану, складеного з урахуванням ГЕРХ | `meal.gerd` |
| Помилка в джерелі | Дослівний опис розбіжності в плані; значення лишається як є | `meal.sourceIssues` |
| Провенанс | Правило: кожне значення — лише з плану, імпорту чи ручного вводу | `packages/core/src/provenance.ts` |
| Стартовий набір | Страви з планів, якими засівається пул сім'ї; файл на сервері | `starter-set.ts` (ядро й веб) |
| Засів | Одноразовий запис стартового набору в порожній пул сім'ї | `seedStarterMeals`, `family.starter_seeded_at` |
| Смак | «Улюблене» / «не подобається»; спільний для сім'ї | `meal_pref`, `TastePrefs` |
| Список покупок | Інгредієнти плану, зведені за категоріями | `packages/core/src/shopping.ts` |
| Охоплення | Чиї плани зводити в список покупок; стан пристрою | `lib/shopping-scope.ts` |
| Відбиток | Хеш змісту плану; позначки «куплено» належать відбитку | `planFingerprint`, `shopping_check.fingerprint` |
| Годинник дня | Коло вікон прийомів їжі на «Сьогодні» | `lib/day-clock.ts`, `DayClock.tsx` |
| Вікно прийому | Проміжок часу слота; налаштування пристрою | `MEAL_WINDOWS`, `slotAt` |
| Фаза неба | Колір тла за активним прийомом | `data-phase`, `Sky.tsx` |
| Стан пристрою | Те, що не синхронізується: активний профіль, охоплення, нагадування | `localStorage` |
| М'яке видалення | Видалення рядком `deleted_at`, фізичного DELETE немає | `deleted_at` |
| LWW | Last-write-wins на рівні рядка (слота) замість CRDT | записи через PostgREST |
| Виведений id | UUIDv5 з природного ключа, щоб дві вставки стали одним рядком | `packages/core/src/sync-ids.ts` |
| V1 / V2 | V1 — один HTML на `main` (GitHub Pages); V2 — local-first на `staging` | `migrate-v1.ts`, `tools/v1-export.js` |
