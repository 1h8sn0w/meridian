# infra — self-host

Тут живе інфраструктура V2: Docker Compose нашого стека, Caddyfile, конфіг
PowerSync і приклад `.env`. Наповнення — **MER-43**; у MER-42 створено лише
каркас каталогу й контракт змінних середовища.

## Що сюди прийде (MER-43)

| Файл | Призначення |
|------|-------------|
| `docker-compose.yml` | Три сервіси: застосунок, PowerSync, Caddy. Підключаються до вже піднятої мережі Supabase як зовнішньої |
| `Caddyfile` | Два хости — застосунок і sync-ендпоінт; HTTPS Caddy бере автоматично |
| `powersync.yaml` | Конфіг PowerSync (Open Edition), монтується лише для читання |
| `.env.example` | Контракт змінних — уже тут, значення порожні |

**Supabase піднімається окремо офіційним compose** — клонується офіційне репо,
каталог `docker/` береться як є. Руками його не дублювати. Порядок запуску:
спершу Supabase, потім наш compose.

## Секрети

Реальні значення живуть лише в `.env`, який у git не потрапляє
(див. `.gitignore` у корені). У репозиторії — тільки `.env.example`.
