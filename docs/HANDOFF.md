# Handoff — Meridian (стан на 18 лип 2026)

Передача контексту для продовження роботи в новому чаті.

## Що це
**Meridian** — планувальник харчування для сім'ї. Бере PDF-плани від дієтолога, розкладає на страви й сам збирає тижневий раціон із пулу: тримає калорійність і структуру дієтолога, але міксує страви з кількох планів. Головний екран показує «що їсти зараз» через годинник дня.

## Тверді правила
1. **Провенанс даних** (див. AGENTS.md). Кожне поле страви/рецепта — лише з PDF, імпорту або ручного вводу. Застосунок **ніколи не вигадує** значень: немає в джерелі → поле порожнє, секція UI ховається. Це медична безпека, не стиль.
   - PDF дає: назву, тип прийому, калорійність, інгредієнти (часто без грамовок), тиждень; БЖВ для частини страв.
   - PDF **не** дає: кроків приготування, часу, порцій, точних кількостей. Кроки/час/порції в макеті рецепта — **ілюстративні**, не реальні дані.
2. **Мова інтерфейсу — українська.**
3. **Жодних російських залежностей, сервісів чи джерел.** Тверда вимога.
4. **Не ускладнювати.** Класичні перевірені рішення, простий читабельний код.

## Робочий процес
- Задачі ведуться в Linear; агент рухає статуси Backlog → Todo → In Progress → In Review → Done і робить PR на кожну задачу.

- Фази = майлстоуни в Linear. Мітки: `poc-core`, `next-wave`.
